# Omen Teleport Study

A Unity prototype exploring high-mobility movement mechanics inspired by
Valorant's Omen and Mirror's Edge.

## Features

- Precise Blink
- Non-Precise Blink
- Sliding
- Coyote Time
- Modular movement architecture
- State-driven movement system

## Technologies

- Unity
- C#
- SOLID
- State Machines
